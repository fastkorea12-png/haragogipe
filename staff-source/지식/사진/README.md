# 레시피 사진

칵테일 카드 사진은 이름 그대로 넣는다: `칼리모초`, `키르`, `미모사`, `퍼지네이블`, `말리부오렌지`, `스크류드라이버`, `블랙러시안`, `뱅쇼`, `샹그리아`. 10/29 페이히어 대표 이미지 8장을 넣었다(미모사는 페이히어에 없음). 확장자는 `.png`도 지원하며 같은 이름의 두 파일이 있으면 JPG를 사용합니다.

`node 도구/빌드.js`는 JPG를 그대로 근무노트에 내장합니다(배포 서버에는 sips가 없어서, 10/28부터). PNG만 macOS `sips`로 긴 변 1000px·JPEG 품질 75로 바꿔 넣으므로, 공개 저장소에는 긴 변 1000px 이하 JPG로 넣습니다. 원본은 바꾸지 않습니다. 사진이 없으면 이미지 칸을 만들지 않습니다.

인터넷 사진은 사용하지 않습니다. 점검용 임시 사진은 제거했습니다.

## 안주 사진
레시피 탭 '안주' 카드 사진은 페이히어 메뉴 이름에서 번호를 뺀 이름으로 넣습니다(10/28 안주 가이드 정리 후): `올리브 8pc`, `아이스크림`, `생초콜릿`, `하몽 덮은 모짜`, `브리 치즈 구이`, `그릴드 소세지`, `버터보드`, `하몽 멜론`, `마르게리따 피자`, `치즈피자`, `치즈&육포`, `치즈플레이트`, `투움바 파스타`, `쉬림프파스타`, `라구치즈 파스타`, `트치소 짜파게티`, `아이스홍시`, `팝콘` (`.jpg`·`.png`). 띄어쓰기·`&`·가운뎃점은 무시하고 맞춥니다. 사진이 없는 카드는 사진 칸이 보이지 않습니다.

10/29부터 안주 사진은 페이히어 매장 상품의 대표 이미지(18장, 720px)를 긴 변 640px·JPEG로 줄여 쓴다. 페이히어 사진을 바꾸면 여기 사진도 다시 받아 넣는다.
