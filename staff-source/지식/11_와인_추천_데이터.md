# 와인 추천 데이터

추천 가능 50종 / 확인 필요 19종. 원문 39종과 웹 자료 기준 추정 11종을 구분한다. 기존38종 점수는 유지했다. 최신 메뉴 연결로 원문 점수3종을 추가 연결했다.

- 웹 추정: 도구/웹추정_맛점수_1011.json의 동일 제품·근거·빈티지·확신도를 함께 보관. 낮음은 제외.
- 웹 추정 맛 점수는 실측값이 아니며 직원용에서만 사용한다. 손님용은 승인된 기존38종만 포함한다.
- 뉘앙스·설명문: 기존 허용 스냅샷67종. 이번 작업에서 다른 탭을 읽지 않았다.
- 가격·품종·도수: List A:H와 K, 2026-10-11 읽음. 가격·재고를 웹에서 채우지 않는다.
- 화이트·로제: 페이히어 판매 목록(2026-10-23, 도구/페이히어_화이트로제_1023.json)이 기준. 번호·가격은 페이히어 값. 판매 목록에 없는 제품은 추천에서 뺀다.
- 미션 레이트 하비스트의 충돌 원문은 보존하며 별도 웹 추정 점수만 사용한다.
- 이름 연결 근거: 도구/와인_이름_연결표.json.
- 재고는 직접 확인.
