# Google Stitch 디자인 요청 — 하라고지페 손님용 와인 취향 페이지

아래 내용을 Stitch에 붙여 넣고, 기존 Welcome 안내지 이미지를 함께 첨부하세요.

---

하라고지페라는 작은 와인바의 손님용 모바일 웹을 디자인해 주세요.
실제 기능 초안: https://fastkorea12-png.github.io/haragogipe/wine/
첨부한 Welcome 안내지를 주요 시각 레퍼런스로 사용하세요. 화면 전체를 새롭게 디자인하되 아래 기능과 데이터의 의미를 보존해 주세요.

## 목적과 이용 흐름
- 손님이 매장에서 QR을 찍어 들어옵니다. 매장 밖에서도 이용할 수 있습니다.
- 와인을 잘 모르는 손님도 오늘의 취향을 쉽게 선택합니다.
- 와인 종류와 취향, 함께 먹을 안주를 골라 추천받습니다.
- 결과에는 추천 와인의 메뉴판 번호가 가장 눈에 띄게 표시됩니다.
- 주문은 별도의 QR 주문 시스템에서 합니다. 이 페이지에서는 와인 번호를 확인·복사하면 충분합니다.

## 분위기
- 조용한 와인바의 종이 메뉴판처럼 따뜻하고 차분하게.
- 아이보리 종이, 테라코타 붉은색, 짙은 브라운 글씨, 섬세한 구분선.
- Welcome과 영어 취향 제목은 읽을 수 있는 우아한 세리프 이탤릭. 한국어 본문은 명확한 글꼴과 충분한 크기.
- 포스터의 감성은 살리되 휴대폰에서 빠르게 선택하기 좋은 화면.
- 직원의 친절한 대화가 떠오르는 표현. 처음 보는 손님도 설명 없이 조작할 수 있게.

## 화면 1 — 오늘의 취향
상단:
하라고지페
Welcome
“오늘, 새로운 와인을 만나고 싶다면”
“마시고 싶은 와인의 성격을 골라 주세요.”
“와인을 잘 몰라도 괜찮아요. 마음이 가는 항목만 선택해 주세요.”

1. 와인 종류: 아직 모르겠어요 / 레드 / 화이트 / 스파클링 / 포트 / 로제.
2. 네 가지 취향: 각 항목은 낮음·중간·높음의 **3단계 선택**입니다. 선택하지 않아도 됩니다. 선택한 버튼을 다시 누르면 해제됩니다.
   - Sweetness 당도: 깔끔한(드라이) ↔ 다정한(달콤하게)
   - Acidity 산도: 차분한(산미 적게) ↔ 발랄한(상큼하게)
   - Body 바디: 산뜻한(가볍게) ↔ 든든한(묵직하게)
   - Tannin 타닌: 순한(매끈하게) ↔ 단단한(떫은맛 있게)
3. 안주 선택: 치즈 / 샐러드 / 육류 / 과일 / 아이스크림 / 초콜릿. 하나 선택하거나 건너뛸 수 있습니다.
4. 주 버튼: “오늘의 와인 만나기”. 보조 버튼: “취향 선택 다시 하기”.
5. 안내: “모르겠다면 그대로 추천받아 보세요.”

## 화면 2 — 추천 결과
- 모바일 세로 카드, 데스크톱에서는 2열. 조건에 맞는 추천 최대 **6종**.
- 메뉴판 번호를 가장 크게: 예) “레드 5번”. 원래 메뉴 표기 “Red Wine 5”는 작게 병기.
- 와인 이름, 종류, 국가, 짧은 설명.
- 당도·산도·바디·타닌 점수는 **5칸 막대**로 표시. 선택 화면의 3단계와 구분하세요.
- 향과 어울리는 음식은 짧고 읽기 쉬운 항목으로 표시.
- 설명이 길면 “와인 이야기 더 보기”로 펼치기.
- 각 카드의 버튼: “와인 번호 복사”. 복사 완료 토스트.
- 안내: “마음에 드는 와인의 번호를 QR 주문에서 찾아 주세요.”
- 조건에 맞는 제품이 없을 때: “지금 조건으로 보여드릴 와인이 없어요. 종류를 바꾸거나 직원에게 편하게 물어봐 주세요.”
- 푸터: “직원과 함께 골라도 좋아요.” / “주문 가능한 와인과 가격은 QR 주문 메뉴에서 확인해 주세요.”

## 반드시 지킬 것
- 로그인, 위치 권한, 시간 제한을 추가하지 마세요.
- 장바구니, 결제, 주문 전송, 주문 완료, 직원 호출 기능을 추가하지 마세요.
- AI 채팅창이나 직원용 매뉴얼·오픈·마감 화면을 추가하지 마세요.
- 와인 번호·이름·점수는 실제 초안 데이터를 보존하세요. 예시 가격·재고·할인·페어링 사실을 만들지 마세요.
- “설정한 취향에 가까워요” 같은 반복적인 선택 이유를 넣지 마세요.
- 작은 회색 글씨에 중요한 안내를 숨기지 마세요. 본문 16px 정도, 터치 영역 최소 44px, 선택 상태가 색 이외에도 분명하게.
- 선택 전·선택 후·추천 결과·긴 설명 펼침·복사 완료·결과 없음 상태를 함께 디자인해 주세요.

최종 결과는 반응형 HTML/CSS로 가져와 기존 추천 로직에 연결할 수 있도록 만들어 주세요.
