# 하라고지페 손님용 와인 취향 페이지

- 공개 URL: https://fastkorea12-png.github.io/haragogipe/wine/
- 접속 제한·위치·로그인 없음. 선택은 현재 화면에만 보관.
- 취향 선택 3단계, 결과 맛 점수 5칸. 종류와 안주 조건을 반영해 최대 6개 메뉴 항목 추천.
- 기존 직원용 추천 데이터의 완성된 맛 점수만 사용. 원본 메뉴 행 번호를 연결해 메뉴판 번호를 그대로 보존한다.
- 손님용 출력에는 이름·번호·종류·국가·품종·맛 점수·향·음식 궁합·공개 설명만 포함한다. 공개 설명은 첫 문단을 사용하여 직원용 자료 확인 메모를 제외한다. 직원용 지식·가격·업무 기록은 내장하지 않는다.
- QR 주문 시스템과는 번호로 연결. 주문 전송·결제 API 연결 없음. 가격은 QR 주문 메뉴에서 확인.
- 빌드: 상위 `staff-source/`의 `npm run build`. `도구/설명_반영.js`로 추천 원본을 갱신한 뒤 빌드한다.
- 배포: 기존 `Update staff assistant` 워크플로에서 직원용과 손님용 페이지를 함께 갱신.
- Google Stitch에는 `Stitch_디자인_프롬프트.md`와 Welcome 안내지 이미지를 전달. 결과 HTML/CSS를 `템플릿.html`의 스타일과 구조에 반영하고 추천 로직·실제 번호를 유지한다.
