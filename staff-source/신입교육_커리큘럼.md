# 하라고지페 신입 교육 커리큘럼

하루 4시간 근무 기준. 기본 5회(20시간), 추가 실습 2회(8시간) 예상. 실제 근무와 교육을 함께 진행하며 숙련도와 혼잡도에 따라 조정합니다.

매일: 설명·시범 30분 → 함께 실습 1시간 → 업무 반복 2시간 → 피드백 30분.

진도: 아직 배우기 전 → 설명 들음 → 함께 해봄 → 혼자 수행 확인. 마지막 단계는 선임이 실제 수행을 확인한 뒤 표시합니다.

## 1일차 · 홀 · 첫 근무

세팅 → 응대 → 정리, 손님 한 팀의 흐름을 여러 번 반복해요. 와인은 위치와 번호를 익히고 서빙은 지켜봐요.

### 매장·식기 세팅

선임과 테이블 번호, 잔·식기·물통 위치를 둘러봐요. 착석하면 물·컵·기본 안주·와인 리스트·메뉴 리스트를 세팅해요.

- 수행 목표: 빈 테이블 하나를 손님 맞을 상태로 세팅하기

### 손님 응대

입장 → 자리 안내 → 세팅 → "주문은 QR로, 기본 스낵은 저쪽에서, 필요하면 벨" 안내 순서예요. 선임과 손님 역할을 바꿔 연습한 뒤 실제 응대는 선임이 옆에서 확인해요.

- 수행 목표: 입장부터 QR 안내까지 선임 앞에서 해보기

### 테이블 정리

손님이 나가면 회수 → 닦기 → 다시 세팅 순서로 해요. 선임 시범을 보고 함께 해보세요. 닦는 도구와 회수 동선은 현장 기준을 확인해요.

- 수행 목표: 정리한 테이블을 선임에게 확인받기

### 와인 번호와 서빙 보기

와인 리스트 번호(Red Wine 1. 등)로 병을 찾고 냉장고·진열장·창고 위치를 익혀요. 선임이 병을 부탁하면 찾아오며 번호를 익혀요. 와인 서빙은 오늘은 옆에서 지켜봐요.

- 수행 목표: 번호 3개를 듣고 병을 찾아오기

### 1일차 시간표

| 시간 | 내용 |
|---|---|
| 0:00–0:30 | 테이블 번호, 식기 위치, 와인 냉장고·진열장 위치 둘러보기 |
| 0:30–1:30 | 세팅 → 응대 멘트 → 정리 시범과 함께 해보기 |
| 1:30–3:30 | 실제 손님 흐름 반복. 와인 서빙은 지켜보고, 병 찾기로 번호 익히기 |
| 3:30–4:00 | 피드백, 진도 표시 |

## 2일차 · 홀 · 와인 서빙과 POS

어제 지켜본 와인 서빙을 직접 해보고 음식 서빙과 POS를 배워요.

### 와인 서빙

라벨 확인 → 코르크 제거 → 향 확인·시음 → 서빙 순서로 선임과 함께 해요. 잔 종류와 코스터, 남은 와인은 칠러에 보관하는 것까지 확인해요.

- 수행 목표: 선임과 와인 서빙을 한 번 진행하기

### 음식 서빙과 식기

서빙 식기 안내에서 메뉴별 포크·나이프·앞접시를 확인해요. 선임과 주문 내용, 테이블, 식기를 대조하고 내보내세요.

- 수행 목표: 주문 메뉴에 맞는 식기를 준비해 서빙하기

### POS 기본

새 주문·추가 주문·서빙 완료·완료 취소·테이블 이동 순서를 확인해요. 먼저 선임 시범으로 배우고 실제 주문 변경은 확인받으며 진행해요.

- 수행 목표: 주문 접수부터 서빙 완료까지 순서를 설명하기

### 특별 서빙과 돌발 상황 읽기

하프·포트 와인 서빙, 잔을 깼을 때, 와인을 쏟았을 때, 남은 와인을 가져갈 때 안내를 읽어봐요. 직접 해보는 건 상황이 생겼을 때 선임과 함께 해요.

- 수행 목표: 상황별 대응을 말로 설명하기

## 3일차 · 주방 보조

조리 전에 주방의 위치와 정리·준비 순서를 배워요.

### 도구·식기 위치

선임과 조리 도구, 서빙 식기, 재료 보관 위치를 찾아보세요. 사용 전후 어디에 놓는지 함께 확인해요.

- 수행 목표: 필요한 도구와 식기를 찾아 제자리에 놓기

### 설거지와 정리

선임에게 세척·헹굼·건조·보관 과정을 시범으로 배워요. 잔 세척은 매뉴얼의 7번 코스·세제 없이 세척 기준을 확인해요. 다른 식기와 세제 사용법은 선임 확인 후 진행해요.

- 수행 목표: 식기와 잔 세척 방법을 구분해 함께 수행하기

### 재료 준비와 조리 보조

소분량·보관·표시 방법, 도구 위생과 기기 조작은 현장에서 확인해요. 임의로 정하지 않고 선임이 지정한 준비 작업을 해보세요.

- 수행 목표: 지정된 준비 작업을 수행하고 보관 상태 확인받기

## 4일차 · 레시피 · 간단한 메뉴

수량과 담는 순서를 보면서 메뉴를 만들어봐요.

### 실습할 메뉴 고르기

올리브·초콜릿·멜론 프로슈토 등에서 선임이 주문 상황과 재료를 보고 2~3개를 골라주세요.

- 수행 목표: 선택한 메뉴의 재료와 식기를 준비하기

### 시범 보고 함께 만들기

기존 레시피에서 수량과 순서를 확인하고 선임 시범 → 함께 만들기 순서로 진행해요. 사진이 없으면 선임의 완성 접시를 기준으로 확인해요.

- 수행 목표: 레시피를 보며 선택 메뉴를 함께 만들기

### 완성·서빙 확인

빠진 재료, 담음새, 식기, 손님 안내를 선임과 확인해요. 같은 메뉴를 다시 만들며 헷갈린 부분을 기록해두세요.

- 수행 목표: 완성 메뉴를 선임 확인 후 서빙하기

## 5일차 · 레시피 · 가열 메뉴와 음료

기기 사용을 배우고 담당 메뉴를 반복해요.

### 가열 메뉴 실습

선임이 고른 피자·파스타 등 1~2개를 실습해요. 매뉴얼의 가열 시간과 순서를 지키고 기기 사용법은 시범 후 확인받으세요. 토치 등 익숙하지 않은 기기는 선임과 함께 사용해요.

- 수행 목표: 가열·마무리·식기 준비까지 함께 수행하기

### 음료 실습

현재 확정된 칵테일·음료 중 선임이 고른 메뉴를 실습해요. [확인] 또는 사장님 확인 전인 레시피는 먼저 확인해요.

- 수행 목표: 잔·재료·수량·제조 순서를 설명하고 만들기

### 담당 업무 이어서 하기

주문 확인 → 준비 → 제조 → 완성 확인 → 서빙·정리를 이어서 해보세요. 어려운 상황에서 누구에게 도움을 요청할지도 확인해요.

- 수행 목표: 담당 업무를 수행하고 보완할 부분 정하기

## 6~7일차 · 추가 실습 · 오픈과 마감

부족한 항목을 반복하고 해당 근무 시간에 오픈·마감을 배워요.

### 부족한 업무 반복

앞선 교육에서 함께 해본 항목을 반복해요. 혼자 수행할 수 있는지는 선임이 실제 작업을 보고 확인해요.

- 수행 목표: 맡은 업무를 스스로 수행하고 선임 확인받기

### 오픈 실습

오픈 근무 때 체크리스트를 선임과 한 번 진행하고 다음 근무에 직접 진행해 확인받아요. 항목을 읽는 것과 실제 실행을 구분해요.

- 수행 목표: 오픈 작업·체크·제출 흐름 익히기

### 마감 실습

마감 근무 때 선임과 함께 진행하고 다음 기회에 직접 해보세요. 손님이 남아 있을 때의 작업 순서와 [확인] 시간은 선임에게 확인해요.

- 수행 목표: 마감 작업·체크·제출 흐름 익히기

## 운영 기준

오픈·마감 체크리스트는 매일 실행·제출하는 별도 업무로 유지합니다. 교육 진도와 연결하지 않습니다. 오픈·마감 각각 선임과 한 번, 다음 해당 근무에서 직접 수행 후 확인받습니다. 배치에 따라 추가 출근이 필요할 수 있습니다.

교육 화면의 안내는 교육 진행안입니다. 메뉴별 수량·시간은 기존 레시피를 사용하고, 확인되지 않은 현장 기준은 선임에게 확인합니다. 교육 진도는 이름 없이 브라우저에만 보관하며 기기 간 공유하지 않습니다.
